How to read these numbers +

Top {{ winmap.top_rep_ids|length }} of {{ winmap.rep_count }} reps by overall close rate. At least three meetings are required to rank; ties break by rep ID. Each objection counts once per meeting. An objection can appear alongside another.

Gaps use Wilson-based Newcombe 95% intervals. Fewer than five meetings in either cohort means insufficient data.

Revenue is estimated, if the rest matched top-cohort close rate (correlational): rest meetings × positive gap × {{ avg_deal_size|money }} average deal. The headline sums sufficient-data rows; overlapping objections may count the same opportunity twice. This is not a revenue forecast.

All fictional seed meetings are included; the dataset covers October 2026. New API submissions update this view immediately.
